### Blender Addons

- **[AudioNotifier](https://github.com/Lauloque/AudioNotifier)** — Audio notifications for long-running Blender tasks.
- **[Autokey Highlight](https://github.com/Lauloque/Autokey-Highlight)** — Visually highlights auto-keyed objects.
- **[bl_reset_custom_properties](https://github.com/Lauloque/bl_reset_custom_properties)** — Reset custom properties to their default values.
- **[convertRotationMode](https://github.com/Lauloque/convertRotationMode)** — Batch-convert animation rotation modes.
- **[GizmoTools](https://github.com/Lauloque/GizmoTools)** — Collection of custom Blender gizmos.
- **[History_Panel](https://github.com/Lauloque/History_Panel)** — Browse and restore Blender undo history.
- **[import_synkscetch_notes](https://github.com/Lauloque/import_synkscetch_notes)** — Import SyncSketch notes into Blender.
- **[LauloqueMayaScriptsDump](https://github.com/Lauloque/LauloqueMayaScriptsDump)** — Assorted Autodesk Maya animation scripts.
- **[LoopMethods](https://github.com/Lauloque/LoopMethods)** — Additional looping tools for animation workflows.
- **[RigAnimTools](https://github.com/Lauloque/RigAnimTools)** — Rigging and animation utilities.
- **[setViewportDisplay](https://github.com/Lauloque/setViewportDisplay)** — Batch-edit viewport display settings.
